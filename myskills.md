## Usage Guidelines

### Primary Skill Selection
For tasks involving Three.js and cinematic storytelling:
1. **Primary**: `threejs-cinematic-design-director` (art direction)
2. **Support**: `3d-web-experience` (engine implementation)
3. **Optional**: `threejs-weather` (if weather effects needed)

### Skill Loading Strategy
- **Maximum 3 skills** in active context
- **1 primary skill** for core capability
- **0-2 supporting skills** for adjacent capabilities
- **Never load** generic frontend/design skills unless specifically required

### Example Usage
```
TASK: Build premium Three.js scroll storytelling site
PRIMARY SKILL: threejs-cinematic-design-director
SUPPORTING: 3d-web-experience
NOT LOADING: generic frontend skills

TASK: Add rain to Three.js scene
PRIMARY SKILL: threejs-weather
SUPPORTING: threejs (if lifecycle work needed)
```

## Anti-AI-Slop Gate

This catalog excludes generic skills that could create template-like outputs:
- Generic frontend skills (replaced by specific alternatives)
- Generic animation skills (replaced by specific cinematic alternatives)
- Generic design skills (replaced by premium-specific alternatives)

All skills in this catalog are specifically designed for premium, original implementations rather than template-based outputs.
